# streety

`streety` - a mod for bonelab that enables you to walk, swim or fly anywhere on earth!

you can:

- explore with your friends via fusion
- warp to different locations by name

and we got:

- navmesh support for ai
- beautiful dynamic lighting
- [Photorealistic 3D Tiles](https://developers.google.com/maps/documentation/tile/3d-tiles) support
- integration with fluid lab

> [!NOTE]
> **RAM Requirements**
> 
> Streety defaults to a 2GB ram allowance to allow it to handle dense areas! Make sure you have some headroom before jumping in.
